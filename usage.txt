Flash-MoE: Universal Qwen3.x-MoE Usage
================================================================================
Supported models: Qwen3.5-397B-A17B, Qwen3.5-122B-A10B, Qwen3.6-35B-A3B
                  (any Qwen3.x MoE with GatedDeltaNet + full attention)

Model directory: the 4-bit quantized model (e.g. mlx-community/Qwen3.5-122B-A10B-4bit)

UNIFIED PREPARATION (NEW! One-command setup)
================================================================================
    cd /path/to/flash-moe
    python prepare_model.py --model /path/to/Qwen3.x-Model-4bit

    This runs steps 1-4 in one shot. All artifacts land in ./prepared/<model_name>/
    ready for the C inference engine.

    Options:
      --output-dir DIR    Specify custom output directory
      --no-repack         Skip expert repacking (for quick setup/debugging)
      --dry-run           Print what would happen without writing

    Artifacts in <output-dir>/:
      model_weights.json   Non-expert weight manifest (auto-detected config)
      model_weights.bin    Non-expert weights (~5.5 GB, mmap'd)
      expert_index.json     Expert byte offsets per layer
      tokenizer.bin         BPE tokenizer data for C engine
      vocab.bin            Token ID → string decoder
      packed_experts/       Per-layer expert files (if --no-repack not set)

    Compatibility: works with all supported Qwen3.x MoE models.

STEP 1 — Generate expert index (DEPRECATED — use prepare_model.py instead)
================================================================================
    cd /path/to/flash-moe
    python generate_expert_index.py --model /path/to/Qwen3.x-Model-4bit

    Output: expert_index.json written into the model directory (~1MB, fast)

STEP 2 — Extract non-expert weights (DEPRECATED — use prepare_model.py instead)
================================================================================
    cd /path/to/flash-moe/metal_infer
    python extract_weights.py --model /path/to/Qwen3.x-Model-4bit --output .

    Outputs: model_weights.bin (non-expert weights), model_weights.json (manifest + config)
    The model config (hidden_size, num_layers, etc.) is auto-detected from config.json.

STEP 3 — Export tokenizer and vocab
================================================================================
    cd /path/to/flash-moe/metal_infer
    python export_tokenizer.py \
        /path/to/Qwen3.x-Model-4bit/tokenizer.json \
        tokenizer.bin
    python export_vocab.py \
        /path/to/Qwen3.x-Model-4bit/tokenizer.json \
        vocab.bin

    Outputs: tokenizer.bin (~20MB, BPE encoder), vocab.bin (~3MB, token id->string decoder)

STEP 4 — Repack expert weights (4-bit)
================================================================================
    cd /path/to/flash-moe
    python repack_experts.py --index /path/to/Qwen3.x-Model-4bit/expert_index.json --dry-run
    python repack_experts.py --index /path/to/Qwen3.x-Model-4bit/expert_index.json

    Options:
      --layers 0-4       repack only layers 0-4
      --layers 0,5,10    repack specific layers
      --verify-only 0    verify layer 0 against originals

    Layout is auto-detected from expert_index.json.

STEP 4b — Repack expert weights to 2-bit (optional, faster but lower quality)
================================================================================
    cd /path/to/flash-moe

    # Test a single layer first (with verification)
    python metal_infer/repack_experts_2bit.py --layer 0 --verify

    # Repack all layers
    python metal_infer/repack_experts_2bit.py

    Note: 2-bit mode is faster but breaks JSON/tool calling (produces \name\ instead of
    "name"). Use 4-bit for production; 2-bit for speed experiments only.

STEP 5 — Build
================================================================================
    cd /path/to/flash-moe/metal_infer
    make clean && make

    No recompilation needed when switching models — the binary reads model config
    from model_weights.json at runtime.

STEP 6 — Inference
================================================================================
    # Single prompt
    ./infer --prompt "Explain quantum computing" --tokens 100

    # With per-layer timing
    ./infer --prompt "Hello" --tokens 20 --timing

    # 2-bit mode (faster, breaks tool calling / JSON — requires Step 4b)
    ./infer --prompt "Explain quantum computing" --tokens 100 --2bit

    # Interactive chat with tool calling
    ./chat

    # Custom model path (all paths auto-discovered)
    ./infer --model /path/to/model --prompt "Hello" --tokens 50
